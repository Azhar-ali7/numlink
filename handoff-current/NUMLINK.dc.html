How to play

Grow a tree of numbers from the start until you've landed on every target. Branch sideways as well as down. Fewer moves beats par.

1Tap an operation (×3, +7, %5, √…). Each has a limited token count.
2Tap any number on the board to build from it instead — that's how a chain forks toward a second target.
3Each arm has a move limit and tokens are shared, so a move that strands a target is refunded.
4One HINT per puzzle. SHUFFLE deals a fresh hand that can still finish the board.
